# V1 reference fixtures: provenance

Both files are **synthetic**. They were generated by V1's `dms/tests/tools/gen_fixtures.py`, byte-identical to V1's `dms/tests/fixtures/`, and verified by the security review (Task 2 check):

| File | How it was generated | sha256 |
|---|---|---|
| `gaze_inputs_cases.json` | `make_face(rng)` with `np.random.default_rng(20260918)` | `a7d7e6dc0d82dd0abd3e03ce84f1891d3403777cb8b1865e744f128b22b698b8` |
| `gaze_inputs_stats_tracker.json` | Gaussian noise around `training_mean`, `np.random.default_rng(7)` | `a214ecec643be881a347abbc4143e19ee0915f8d0cb0b58a938b85b551d8f566` |

The sha256 values above are of V1's files byte-for-byte, as the review measured them. Each ends in CR LF. The repo's `.gitattributes` (`* text=auto eol=lf`) stores them with a final LF instead, so the committed blobs hash to `40796ab493276e57baaf47f5d52153a4dcae325a89382f3d8840b33a0b89730d` (cases) and `206bef65081e418390da8ef78a0234566a1228c90b692ef3c13c71e86e7c5c12` (tracker). The content is otherwise identical.

No real person's face is in either file. They are test oracles only. V1's `onnx_parity.json` came from a source of unknown origin, so it is deliberately not included.
